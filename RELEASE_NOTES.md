# WinArchiveFSPro 0.2.0

- Native C++23 core, C++/WinRT WinUI 3 application, native WinFsp mounts and UNC agent.
- SquashFS, DwarFS and EROFS creation and reading, including official DwarFS 0.15.10.
- Parallel random reads, shared image caches and configurable memory use.
- Multi-source creation, eight compression presets, advanced controls and Explorer integration.
- English and Simplified Chinese interfaces.
- MTP/PTP and Android ADB/ADB Root read-only UNC device access, nested images, device management and progress notifications.
- Internal symbolic-link resolution, recursive search, batch creation/extraction, multiple UNC directory aliases, and configurable aggregate decoded-data cache.

- Read-only ZIP, 7z, RAR, TAR and compressed TAR, CPIO, CAB, ISO9660, AR, LHA and single-file compressed streams; TAR payload and sparse extent indexing, and in-memory decoder cursor reuse.
- Architecture-specific installers and portable distributions for x64, x86 and ARM64.
